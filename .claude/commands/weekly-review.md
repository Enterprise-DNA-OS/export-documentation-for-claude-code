---
description: The Monday review, written from attention, cut-offs, documents outstanding, credits and money owed.
---

Run `npm run trade -- attention`, `npm run trade -- cutoffs`, `npm run trade -- lcs` and `npm run trade -- receivables`. Write five lines: what sails this week and what could miss it, the rule breaches to fix first, the credits with a bank date this week, who owes money, one change to a market or customer requirement worth making. Then run /draft-weekly to save it.
