description: The morning desk check: cut-offs in the next 14 days, export entries to lodge, documents outstanding, and goods arriving with documents not yet sent.
---

Run `npm run trade -- cutoffs`, `npm run trade -- entries`, `npm run trade -- docs-due` and `npm run trade -- arrivals`. Write it as a list in cut-off order: shipment, customer, what is missing, who to chase, and the time the export entry must be in. End with anything that cannot make its sailing.
